🧰 Question Manager

Import JSON → Auto-create Bank → Never mixes with other banks. Supports Bilingual JSON (see template).

Supported JSON formats for future bilingual:
Form A: { question, question_en, options, options_en, explanation, explanation_en }
Form B: { question: {hi, en}, options: [{hi,en}...] }
Form C: { question_en, translations: {en:{...}, hi:{...}} }
Topics are auto-detected from file — only those topics will be shown in UI.
💡 Local vs Global: Import above saves only in YOUR browser. To make it visible to EVERYONE on https://vijaysingh147.github.io/Quiz/ → Click 📦 button, then unzip and push `database/` + `banks.json` to GitHub. See video in README.

🚫 Hidden Banks

Built-in banks are hidden (not deleted). You can restore them here. Custom banks are deleted permanently.
